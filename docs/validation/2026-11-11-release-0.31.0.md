## 失败与边界保留

- GitHub CI [43131575689](https://github.com/ckanner/flywheel/actions/runs/43131575689) 和发布 [43131577361](https://github.com/ckanner/flywheel/actions/runs/43131577361) 均因账号付款／spending limit 未能启动；本机检查不冒充 Actions 通过。
- macOS 最初遇到累计 600 秒包级超时，最后一个测试仅执行 2 秒；后续全量测试完成。原始 `make quality-gate` 的覆盖率拒绝记录保留，不将补充测试后的合并覆盖率冒充原命令一次通过。
- Linux 初次覆盖率发现并行预算／取消时序分支缺口，增加确定性预算耗尽与报告收集失败用例后，完整原始门禁通过。插件测试按文件串行，保留原有断言和截止时间。
- Claude Code Pro 0.4.0 使用已审阅的真实 tarball，SHA256 `125951f39d27a87072a9dc20c622a19089ad7ba84b69ba6228e1fbb03f46f581`；不改版本、不伪称 registry 已发布，不接受跳过作为通过。
- npm 接收上传后部分版本超过首次 180 秒公开查询窗口。保持原候选，仅重复只读核对；一个 npm 只读查询进程曾 SIGABRT，后续查询恢复。六包公开完整性和官方安装均另行确认。
- 原生桌面验收使用已有隔离 mock 任务，故意失败的历史 L1 保持失败；不重跑真实模型、不更改历史 Session header、不为旧记录缺失的项目身份伪造值。
- 不能分离项目归属与沙箱根的原生 `workspace-write` 后端仍明确拒绝不支持的组合，不自动扩大权限。SDK 无推理探测不能证明账号额度、真实模型质量或历史恢复效果。
