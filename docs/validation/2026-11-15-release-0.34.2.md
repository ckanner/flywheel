## 样式与安装边界

用户红框对应 Tab 的 hover 背景，不是独立浮层。旧样式的 48px 高度、零左右 padding 和
直角造成竖窄背景。流程导航和节点子导航保留样式统一为紧凑圆角目标、独立下划线，分段
按钮限制高度；键盘、禁用与触控行为保留。真实 Chromium 六组宽度／指针测试通过，旧
CSS 先在同一检查中失败。可选浏览器检查并非默认 CI 项，细节见实现记录。

桌面验收准备了独立 Go 示例任务，仅执行 `run --only verify`，结果 passed、running=false、
Provider sessions=0，并通过公开 CLI 登记到原离线验收会话的真实 hostSessionId，供安装后
验证两任务切换。没有伪造会话事件或手写 state.json，也没有发送模型请求。

安装前 Mac 锁屏，已请用户解锁；本轮尚未替换全局 CLI 或 desktop 插件、未修改用户配置、
未重启 DSH。实测两处仍为 0.34.1。解锁后继续确认没有活动任务，再备份、安装正式版本、
按既有授权应用完整默认配置，并验收多任务导航、刷新保持选择及导航交互。不得把离线／
registry 安装验证当成已完成用户桌面升级。
