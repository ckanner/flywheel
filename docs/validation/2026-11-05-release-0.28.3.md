## 发行复核修复

真实 Go worker 子进程回归复现：ready 后直接 exit 1、损坏终态以及错误 settings 均返回 TRANSPORT，但 CleanupError 为空，旧引擎可继续传输重试。补充独立清理确认事实，只有完整且匹配的终态才能确认 SDK shutdown；worker 已启动却无可信回执时保留协议诊断并停止本次运行。正常 provider 错误的已确认清理仍保留原重试策略，启动失败不误报遗留进程，取消与超时优先级保持。损坏 AUTH 尾帧同样覆盖为 TRANSPORT 与清理未知；所有终态（含取消）校验已知 session 身份。

原 error-before-timeout 用例仅留 100ms 启动真实 Go test 子进程，本机负载下可在发出 AUTH 前就超时，未覆盖其宣称的顺序。为 admission 预留 2 秒，仍验证收到账号错误后物理超时且保留 TIMEOUT 优先级；生产 watchdog 和测试断言未放宽。
