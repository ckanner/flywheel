# DSH 0.2.2-rc.2 兼容复核（Flywheel 0.31.1）

用户桌面已更新到 DSH `0.2.2-rc.2`。已发布 Flywheel 0.31.0 的 `engines.dsh`
只列到 `0.2.2-rc.1`，宿主因此跳过整个 DSH 插件；本记录覆盖 0.31.1 的兼容声明、
测试与真实宿主挂载。

## 结论

- 0.31.1 的 `engines.dsh` 为 `0.2.1-rc.5 || 0.2.2-rc.1 || 0.2.2-rc.2`；
  未知版本仍由宿主拒绝，不需要 exact-version exemption。
- `npm ci --ignore-scripts` 在本机通过；`dsh-subagent-codex-pro` 仍由
  `file:vendor/dsh-subagent-codex-pro-0.9.0.tgz` 解析，未依赖不存在的 registry 版本。
- 插件测试在 rc.2 宿主包上通过：216 passed / 0 failed / 24 skipped；发布版
  renderer 的 legacy-host 检查 9/9 passed。
- 真实 DSH `0.2.2-rc.2` 组合中，0.31.1 不再出现 `skipping profile bundle`；
  唯一剩余警告是无关的 `@deepseek-ai/dsh-web-search-exa@0.2.2-rc.1`。
