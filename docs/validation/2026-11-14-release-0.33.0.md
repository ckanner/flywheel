## 桌面验收失败与后续修复

重载后视图出现，但任务与配置读取报 `generated Remote flywheelConsole/read field "sessionId" has no strict codec`。
因此 **0.33.0 的桌面读取验收失败**，不能用源码／候选或 SDK 通过代替。

客户端原来用 src-json 挂载只读 Remote，旧 renderer 测试模拟了 `$mount`，Host 测试则直接调用
Gateway，遗漏真实 Client 注册。这一 descriptor 在 v0.32.1 源码中已经存在；不能据此次失败
倒推旧版本曾完成该路径的真实验收。当前 DSH 0.2.2-rc.3 要求 strict 输入 codec。

后续 0.33.1 保留单包结构，补充有实际校验的公开 codec 工厂，并让打包 Client descriptor
通过真实 Client 和 Host Gateway。0.33.0 产物与标签保持不变；补丁的实际验收另行记录。
