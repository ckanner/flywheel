## 失败与恢复

1. macOS 首轮继承错误 GOROOT，改为命令级固定 Go 1.27.3。其后全量 machine 测试出现累计 600 秒超时；串行包运行也曾超时。没有放宽 timeout、覆盖率或断言。确认环境中的 Git shell wrapper 带来每次调用额外进程开销后，测试使用同一 Git 2.53.0 原生可执行文件及等价配置，最终 machine 包 297.850 秒、完整门禁通过。该测试环境不写入用户 launcher。
2. Linux 首轮 npm 遇到 root 拥有的缓存目录 EACCES；仅改用可写的独立 npm cache，继续以普通用户完成全量门禁。
3. 多次 npm 网页认证会话过期。重试只复用原始候选，先核对 registry 完整性；不重建同版本，也不依据用户点击完成就认定上传成功。
4. 入口包被 npm 接收后，公开版本暂不可见，首次公开安装返回 ETARGET。等待传播后，同一版本安装通过；未重传不同内容。
5. 提升第五个 `latest` 成功后，远端标签读取一次失败（exit 128），流程停止。重新运行同一提升程序，先重新核对源码／远端标签／候选／公开安装回执，跳过已完成的五个标签，再提升入口包；最终 `verifyLatest` 和源码／远端标签检查均通过。
