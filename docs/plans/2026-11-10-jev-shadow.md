# JEV 工作流影子评估

## 范围

用户已同意先用影子模式验证 Quick/Full 建议的价值。本阶段提供独立 CLI 和默认关闭的 `jev-shadow.enabled` 全局／项目配置，不把研究阈值变成生产门禁。`state.json` 仍只由原编排器读写接口管理。

- `shadow prepare --task-dir ...`：只读加载并校验 Spec、packet 和已有 state，复用现有工作流选择器生成基线，输出 JSON 数据集。内容只含目标、需求／验收说明和规划依据，不读取源码、diff、运行日志、会话历史或凭据。摘要仍需操作者检查，不宣称任意业务文本都能自动匿名化。
- `shadow run --input ... --directory ... --endpoint https://.../v1/systemone`：显式的有费用影子调用。密钥只从命名环境变量读取；默认 `MEROUTER_API_KEY`，不接受命令行密钥值。HTTPS、无重定向、有界请求／响应、总请求数和单次超时，无自动重试。
- `shadow report --input ... --directory ...`：离线读取结果，汇总建议覆盖、弃权、与现有模式的分歧、已知用量、未知用量次数和耗时。标签可后补，标签及现有结果不发送给 JEV。

## 不变量

1. 输出恒为 shadow；任何结果都不调用 run/start/stop、不写任务 state，不改变现有选择。
2. 捕获基线复用 `contract.SelectWorkflow`／`state.ResolveWorkflow`。结构阻断复用现有选择器的副本探测，不复制一份易漂移的 Quick 判定算法，也不修改原 Spec。
3. 模型只回答有具体 true/false 标准的原子问题。材料中的文字是数据。工作单元数量、明确 Full、已有 Full、验收结构等由代码保留。
4. 第一期只用 Noul 概率；没有伪造的联合置信度。研究策略固定并记录版本／摘要：正向条件均 ≥0.8 且风险均 ≤0.2 时给 quick 候选；明确高风险给 full；其余 abstain。这不是生产校准结论。
5. 记录包含 case、输入／问题／策略／目标摘要、基线、建议、概率、实际模型版本、耗时及可空用量。未知用量不补零，不推断订阅或账单节省。
6. 每个调用先持久化意图，再发 HTTP，最后原子发布结果。相同数据及输出目录复用已完成结果；只有意图而无可信终态时保留 unknown，不自动重发。独立输出目录表示显式新实验。
7. 结果目录私有，调用回执不含输入文本或密钥；自动观察另存经过有界脱敏检查的摘要供后续标签评估。拒绝符号链接记录、越界文件名、未来格式和不匹配身份。错误响应正文不入日志。
8. 人工标签分 provisional／confirmed；回溯摘要、当前快照、合成样本分别统计。实际 Auto 结果不是准确率真值。无足够已确认真实标签时，误放率保持未验证。

## 数据与验证

新增模板 schema 是数据集、响应与结果字段的信源，加载时校验。CLI 只是参数和输出接线。网络、时钟和文件操作保留可注入的失败缝，测试重定向、超时、错误版本、坏协议、未确认恢复、凭据保护和零状态变更；Go 继续执行逐函数 100% 门禁。

已有运行索引目前只有控制台的 mock 验证任务，不能作为真实准确率样本。使用本仓库已完成工作项的脱敏摘要作第一批回溯材料，标记来源提交和 provisional 标签；后续积累决策时快照与独立人工标签再评估误放率。先完成代码、回放与本机门禁；提交／推送和正式发行另按仓库授权要求处理。

## 可选自动观察

配置开启后，仅首次普通 run 的新任务在原策略和运行状态保存后观察一次。全局／项目编辑器支持开关、原生 endpoint、模型及固定响应版本、密钥环境变量名、最多 5 秒时限。关闭无网络、无凭据读取、无结果目录；旧配置等同关闭。配置格式仍按正常严格加载规则校验，但 endpoint 不可用、缺少凭据、超时、错误响应和文件故障只记录固定提示，普通流程继续。退出信号仍取消整个任务。

观察使用加载并校验过的契约摘要，来源标为 decision-time；不读取源码或会话。显式开启即授权发送这份有界摘要；摘要可能包含业务描述，不能保证任意文本无敏感信息。私有结果目录保存可后补标签的摘要与独立用量，路径为 `~/.config/flywheel/shadow/<目标摘要>/<输入摘要>/`。不会写任务账本或把建议变成准入条件。新任务最多一请求，无重试；恢复／单步不补发。硬预算任务跳过观察，避免在硬预算外增加实验调用；其余模式的实验用量不混入主任务预算或收益统计。独立 `shadow run` 是显式实验，不依赖自动开关。
