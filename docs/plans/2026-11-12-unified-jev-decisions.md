# JEV 总开关与反馈驱动取证

[方案索引](README.md) · [当前 JEV 指南](../zh-CN/jev.md) · [验收记录](../validation/2026-11-12-unified-jev-decisions.md)

## 目标与基线

基线为 main `e035b5b5736c2d26da7ada2bf1ca97ee020fd5a2`（源码 0.31.1）。原实现
已有有界决策与调查采用，但桌面只有旧 `jev-shadow`，Task 默认不创建决策策略；
真实采用主要改变动作顺序，预算充足时仍运行全部动作。

本次目标：一个 `jev.enabled` 控制全部已支持的在线 JEV 功能。关闭时保持原路径，
开启后自动参与实际调查选择、冗余取证跳过和提前转入报告。保留 Task／New／Run
以及 Auto／Quick／Full，不引入第二套面向日常用户的模式树。

## 架构决策

### 配置拥有启用权

新增 `jev` 配置，唯一布尔开关为 `enabled`。目标地址、固定版本模型、凭据变量名、
超时、调用上限、概率阈值与允许的数据类别为运行边界。配置继续按任务、项目、
全局、内嵌表选择一份完整文件。项目关闭不能被全局开启或任务输入中的旧模式绕过。
路径发现必须处理默认 cwd、Git 子目录、物理路径与相对任务路径。

创建调查时由 Go 自动解析并冻结有效策略；宿主仅提供目标、假设和批准的取证动作。
Start 不发 JEV 请求。Run 负责循环、回执、选择及原子状态更新。新任务不再手写
`decision.mode`，也不因使用 Task、New 或 Run 而获得不同的开关语义。

### 运行中的关闭和恢复

请求前、返回后、采用前重核当前开关与权限边界。关闭或不再相容的策略回到合法
基线；已经发出的请求仍按冻结身份核对。未知请求计入上限且不重发，未知实际动作
仍阻断。重新开启不重置预算或历史。原本未冻结 JEV 策略的准备记录继续原路径，
新准备记录才采用新开启的配置。

当前状态展示区分配置启用值、最近观察到的运行状态、实际采用结果和取证控制
效果。仅保存配置不能显示为已经采用，历史快照不能显示为实时配置读取。

### 取证控制也必须有具体绑定

保留 Go 实现的 `read_file`、`search_text`、`list_files`。在真实观察满足前提时，
由 Go 生成额外有限选项：

| 选项 | 机械前提 | 效果 |
| --- | --- | --- |
| 执行下一项动作 | 属于剩余批准动作；目标及状态身份一致 | 执行原 Go 处理器 |
| 跳过一项冗余动作 | 涉及的假设已有成功、未截断且候选仍匹配的观察 | 记录被跳过的动作及观察引用 |
| 进入报告 | 所有假设均有上述有效观察，且仍有未执行动作 | 停止收集，进入 awaiting-report |

JEV 在这些候选中选择。采用仍校验输入、模型、概率、当前状态和候选绑定，并将
回执消费与效果记录一并 CAS 持久化。跳过和提前报告不增加文件权限，不创建 shell
命令，不声称假设成立或根因已经证明。分析者提交报告时必须保留观察引用及局限；
修复继续使用原实现范围和验证／review 门禁。

### 退役重复路径

删除普通运行的影子观察器和独立影子网络客户端。旧 `jev-shadow` 仅保留读取迁移，
不能把原本只批准本地捕获的设置变成在线权限。桌面只保留 JEV 总开关，保存即可
生效，不设置第二次“开启并保存”确认框。旧 `shadow` 命令只返回迁移提示。

统一 `decision replay` 与 `decision evaluate` 继续作为开发工具。Replay 纯本地，
不依赖开关；evaluate 使用同一总开关、目标、凭据和配置上限，强制只建议，不执行
动作。取消发生在真实请求中时保留未知回执，本次返回 143；以后读取该未知回执
返回 3，不将历史取消当作新取消，也不重新请求。

旧快照的请求问题文本和摘要必须仍可校验。新增控制语义放在新的动作描述中，
避免无版本更新破坏旧 QuestionHash。历史方案、原始评估及验收记录不重写。

## 与“快是一种方法”的关系

本次把“更快选一项动作”扩展为“依据反馈减少剩余取证”。确定性动作直接执行，
JEV 只在有可选分支时参与。关闭时不为每个动作重复解析不可能采用的 JEV 策略。
提前结束的语义边界保持为交给分析者，而不是以概率替代验收。

当前仍保留选择前后对批准路径的候选摘要检查，尚未以缓存或局部哈希替代。它有
读取开销，但不能在缺少等价失效证明时直接删除。当前真实采用族仍为调查；修复、
replan 和模型路由的协议枚举不会因此自动获得执行权。后续新增已验证的决策点应
复用同一开关和配置解析，不再增加功能开关。

## 验收与衡量

代码验收覆盖总开关、优先级和迁移、Task 等价公开调用、关闭时零请求、开启时真实
采用、证据不足不提前结束、输入改变拒绝旧建议、取消／未知／恢复、报告与修复
移交，以及桌面显示。Go 保持每个函数 100% 语句覆盖门禁，运行核心 race、插件
行为测试及三个 Provider 跨进程桥接。

离线服务 fixture 可以证明分支真的生效、动作减少和恢复正确，不能证明真实模型
质量或净耗时收益。真实效果需要完整任务对照：有效证据时间、执行／跳过动作数、
总耗时、JEV 自身耗时、实际／未知用量及最终质量。本次不发付费请求，不更改用户
机器配置，不发布 npm，也不把源码完成等同于 Mac 桌面已验收。
