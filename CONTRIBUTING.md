# Contributing to Flywheel

English · [简体中文贡献指南](docs/zh-CN/contributing.md)

Read the [contribution guide](docs/en/contributing.md) for the development
setup, architecture constraints, validation requirements, and pull request
workflow.

Documentation changes follow the [maintenance rules and review checklist](docs/en/contributing.md#keep-documentation-organized)
([中文规范](docs/zh-CN/contributing.md#保持文档结构清晰)). Use the change-to-document
table to identify affected guides, update their owning sections, and keep the
English and Chinese editions in the same PR. The [documentation index](docs/README.md)
explains where current guides, proposals, and dated evidence belong.

AI agents must also follow [AGENTS.md](https://github.com/ckanner/flywheel/blob/main/AGENTS.md)
for task scope, repository contracts, validation, and authorized delivery.
